# Halaman Pemblokiran Spectra

Halaman pemberitahuan akses diblokir untuk jaringan Spectra Solusi Global. Halaman ini menampilkan informasi diagnostik yang tersedia di browser, ID insiden, dan tautan untuk menghubungi administrator.

## Menjalankan secara lokal

Pastikan Node.js dan npm sudah terpasang, lalu jalankan:

```sh
npm install
npm run dev
```

## Pemeriksaan

```sh
npm run lint
npm run build
```
